This is the preview branch for the "canvas" version of fridg3.org.

This branch includes modifications that allow the page to be used in GitHub pages without losing any visual functionality. The following adjustments have been made:
- Content that requires PHP now contains placeholder content, and can be displayed without the use of `index.php` (not including `/admin`)
- Images have been added back to most pages (not including `/blog` and `/music/cactile`)
- Email submission form now displays a pop-up referring to the `me@fridg3.org` email address when it would've submitted
- A disclaimer clarifying this information has been added to the homepage

If you wish to use this version of the website for your own purposes, you should instead use the main branch or Google Drive archive, as to ensure all PHP functions as originally intended.
